# Asian Vibrant — Pre-Build Stub

Archived 2026-05-24, when the full Asian Vibrant theme shipped.

These files were the placeholder scaffolding that kept the theme
registry compiling while the real visuals were under construction:

- `shell.tsx` — full-screen "coming soon" overlay with a "back to
  Frutiger Aero" escape button. Replaced by a pass-through shell.
- `stubs.ts` — single `NullStub` component re-used for every
  per-surface slot in the manifest. Replaced by real Asian Vibrant
  components under `web/src/themes/asian-vibrant/components/`.

Kept on the off chance the project ever needs a stub-theme pattern
again for a future incoming theme.
