# Asian Vibrant

Stub theme. Intended aesthetic:

- Crimson + gold + soft pink. Lacquered surface with brushed gold edges.
- Sumi-e ink brush textures as decorative overlays.
- Anime cell-shading on cards: hard borders + flat fills + no glow.
- Display font: a heavy slab or kanji-inspired display face.
- Body font: clean grotesque (kept HitmarkerText for now).
- Layout: editorial / magazine grid, diagonal flow, ink-stamp accents.
- Motion: sliding paper screens for transitions, ink-bleed on hover.

When this theme is built out, the placeholder shell goes away and each
surface in `components/` is replaced with a real React component.
